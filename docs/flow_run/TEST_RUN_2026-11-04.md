## Cancel and amend on screen

Material Consumption MC-2026-00030 and Cash Bank Voucher CBV-2026-00026 were cancelled with the Cancel button (one confirmation, no Cancel All dialog). Rice stock went 40 to 65 on cancel and 45 after the amended issue of 20. Journal Entry followed the voucher.

## Defect found

**Amend fails on Material Consumption and Cash Bank Voucher.** The Amend button copies the old `stock_entry` (or `journal_entry`) link into the new draft. Save then stops with "Cannot link cancelled document: Stock Entry MAT-STE-2026-00031" (Journal Entry ACC-JV-2026-00025 for the voucher). Clearing the field by hand lets the amendment go through, which is how the run was finished. The Principal tests added in `test_roles.py` copy the document in Python, which honours `no_copy`, so they did not catch it. The screen's Amend copies all fields, including `no_copy` ones.
